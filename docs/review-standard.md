# 章序一致性核对准则 v1

说明日期：2026-10-26。适用于当前 0.2.0 版本的规则检查与可选 AI 语义审稿。

这是章序根据现有实现公开的产品准则，便于作者了解依据、核对结果和反馈误报。它不是行业认证、平台发布规范或商业潜力评分标准。

## 依据哪些材料

| 材料 | 当前用途 | 限制 |
| --- | --- | --- |
| 作者确认的设定与别名 | 作为规则比较基准；相关条目随所选原文提供给 AI | 设定必须能回到稿件原文；未确认候选不成为规则基准 |
| 导入、收录的旧稿原文 | 提供原有事实及其上下文、引文出处 | AI 每轮只覆盖已发送片段，未提及不等于没有发生 |
| 本次新章原文 | 提供待比较的事实、叙述时间和变化解释 | 规则只识别有限句式；AI 可能误解或遗漏 |
| 作者对疑点的判断 | 保留错误、正常变化、误报及备注 | 仅在相同稿件与设定语境下恢复，不自动训练模型 |

当前没有独立的任意世界观规则库、外部事实检索或完整故事时间线。作品中的魔法、复活等设定应按作品内部叙述理解，AI 提示词明确要求不要凭外部常识推断世界规则。

## 如何提出疑点

### 规则检查：明确属性比较

1. 只取已确认且原文引用有效的设定；通过作者确认的别名归并对象。
2. 对同一对象、同一属性进行比较。同一属性有多条已确认记录时，以当前新章之前最近收录章节中的记录为基准；同章按原文位置取后者。这是收录顺序，不等于故事时间。
3. 对常见中文数词、左右撇子等同义表述进行规范化；长度只在同一度量体系内换算。规范化后相同，不产生差异。
4. 惯用手、瞳色、血型、生父、生母、出生地、固定编制、长度目前属于稳定属性；值不同且未识别到语境线索时标为“明确属性差异”。稳定属性仍可能因剧情、设定调整或提取错误发生变化，不能直接当作作者写错。
5. 年龄、阵营、生死状态的差异，以及含回忆、话语、传闻、疑问、伪装、梦境、明确变化或时间推进线索的差异，交由作者结合剧情判断。规则的语境识别范围有限，可能漏识别。

实现位置：[engine.js](../dist/engine.js) 中的 `ATTRIBUTES`、`normalizeValue`、`activeFacts`、`contextFor`、`checkDraft`。

### AI 审稿：语义冲突判断

提示词要求模型遵守以下准则；这些要求不能保证模型始终执行正确：

1. 仅使用本轮前文、相关已确认设定、别名和新章；识别同一人物或对象的不同措辞与合理指代。
2. 先判断是否存在回忆、梦境、伪装、传闻、不可靠叙述、时间推进、康复或复活、关系或阵营转变等解释。前文或新章已明确解释的正常变化不报告。
3. 解释缺失且两处叙述难以同时成立时，提出冲突疑点。仍有实质矛盾但时间或指代需确认时，明确标注语境待确认。两类都由作者最终裁定。
4. 片段没有提到某件事，不能据此断言它没有发生；不能把人物传闻或对话直接当作客观事实。
5. 不联网、不套用外部常识推断世界规则、不改写正文、不为了凑数量报告。

例如，旧稿写人物失明，新章写其看清旗号，应先寻找治愈、特殊能力或叙述时间的解释。有明确解释应跳过；缺少解释时可提示作者核对。例子说明预期准则，尚不是已通过真实模型验收的案例。

实现位置：[ai-service.mjs](../server/ai-service.mjs) 中的 `SYSTEM_PROMPT`；[semantic.js](../dist/semantic.js) 中的 `buildSemanticContext`。

### 证据要求：每条结论可回查

- 旧稿原文、新章原文、章节与字符位置、疑点原因必须能够展示。
- AI 返回的两段引文必须逐字存在，并可在指定旧稿片段及新章中唯一定位；改写、拼接、找不到或重复的返回会被剔除。服务器与浏览器均执行校验。
- 引文有效只证明原文存在，不能证明两段事实确实冲突。AI 结果统一作为疑点展示，由作者选择确有错误、正常变化或误报。

实现位置：[semantic.js](../dist/semantic.js) 中的 `validateModelIssues`、`semanticFindings`；[engine.js](../dist/engine.js) 中的 `validateEvidence`。

## 如何验证这套标准

当前已完成规则、检索、引文校验、API 合同和异常处理的自动测试。AI 响应使用明确的测试夹具；尚未配置真实模型密钥，尚未完成真实 DeepSeek 推理或真实作者样稿评估，不能据此声称识别准确率。

后续应由授权作者或编辑为样稿标注：是否冲突、涉及原文、变化解释和应有结论。样本同时包含真实错误与正常推进、倒叙、不可靠叙述、别名、单位换算和信息不足等反例。以这些人工标注评估误报、漏检及证据完整性，并单独保留未用于调整规则的验收样本。完成这一过程前，不宣称商业可用的准确率或召回率。
